# Tamagotchi-Pet

This is a Tamagotchi pet design, designed by me. 
I made this project with the help of the "Starbie" and the "Tamagotchi" guide provided by Hackclub. I tweaked the design, by combining both of them.

This project is a small electronic pet, that you can take around with you to... well, anywhere. As, this project has its own IMU's and temperature and pressure sensors. This project acts like a small pet, whom you can feed, and as well as play with. The files containing every thing required for this project is already included in the repo. Also, this pet can be travelled with, as it contains a 2500mah Lipo battery, which can let it be working for atleast 20 hours after charging. This can also be travelled with, by attaching it to your backpak, with the hep of a lanyard cable, inserted through its carry loop.
